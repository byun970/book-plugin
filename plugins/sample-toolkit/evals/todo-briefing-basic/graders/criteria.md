성공적인 응답은 다음을 모두 만족해야 한다.

- ID, 제목, 상태(완료/미완료) 열을 가진 마크다운 표가 포함되어 있다.
- 표에 담긴 각 항목의 제목이 todo-api MCP 도구(listTodos) 호출 결과에 실제로 존재하는 title과 일치한다. 지어낸 항목이 있으면 실패다.
- userId=1 필터가 적용된 결과만 보여준다.
- 할 일을 3개까지만 보여준다.

다음 중 하나라도 해당하면 실패로 판정한다.

- MCP 도구를 호출하지 않고 답을 지어냈다.
- 표 형식이 아니다.
- 3개보다 많거나 적은 항목을 보여준다(단, 실제 데이터가 3개 미만이면 예외).
