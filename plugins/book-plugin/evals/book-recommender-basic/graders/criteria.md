성공적인 응답은 다음을 모두 만족해야 한다.

- 제목, 저자, 출간연도 열을 가진 마크다운 표가 포함되어 있다.
- 표에 담긴 각 책 제목이 book-api MCP 도구(recommendBySubject) 호출 결과에 실제로 존재하는 title과 일치한다. 지어낸 책이 있으면 실패다.
- science_fiction 주제로 조회한 결과다.
- 책을 3권까지만 보여준다.

다음 중 하나라도 해당하면 실패로 판정한다.

- MCP 도구를 호출하지 않고 답을 지어냈다.
- 표 형식이 아니다.
- 3권보다 많거나 적은 항목을 보여준다(단, 실제 데이터가 3권 미만이면 예외).

다음은 실패로 판정하지 않는다.

- Open Library의 subject 태깅은 크라우드소싱이라 느슨해서, `science_fiction` 주제로 조회해도 엄밀히는 SF 장르가 아닌 고전(예: 《이상한 나라의 앨리스》, 《오즈의 마법사》)이 섞여 나올 수 있다. 이 플러그인은 업스트림 API 응답을 그대로 전달하는 것이 역할이며, 장르 분류의 정확성 자체는 검증 대상이 아니다. subject 파라미터가 `science_fiction`으로 올바르게 전달되었고 결과가 실제 API 응답과 일치한다면, 책의 장르가 실제로 SF인지는 채점 기준에서 제외한다.
